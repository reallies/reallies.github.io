# SW20 — 날씨 맞춤형 패션 광고 포토문자 자동화

> **연계 기업의 기존 문자 발송 서비스 위에 AI 생성 레이어를 얹기로 결정한 기업연계 5인 팀장**
> `팀장 · 기획 · AI 파이프라인` · `5인팀` · `2024.09–12` · 기업연계 프로젝트

## 🎯 문제

온라인 편집샵의 광고 문자가 단순 할인 정보에 의존해 소비자 피로도가 높다. 현재 날씨에 맞는 '필요성'을 제안하는 고관여 마케팅이 필요했다.

## 🛠 핵심 구현

- **AI 이미지 생성 파이프라인** — 날씨/계절 → 프롬프트 생성 → DALL·E 이미지 생성 (`generatePrompt.js`·`seasonalprompt.js`·`openAI_Image.js`)
- **프롬프트 엔지니어링** — 생성 이미지에 불필요한 문자·숫자가 섞이는 품질 저하 문제를 프롬프트 개선으로 해결
- **패션 아이템 선택 로직** + **포토문자 발송·주소록 관리** (`routes/message.js`·`contacts.js`)

## 🧱 기술 스택

| 구분 | 기술 |
| --- | --- |
| Backend | Node.js/Express · MySQL(mysql2)+SQLite · JWT/bcrypt · **sharp(이미지 처리)** |
| AI | OpenAI (DALL·E) |
| 외부 | 기상청 API · 포토문자 발송(뿌리오 API, 기업연계) |

## 👤 역할 · 기여

5인 팀 팀장(오현석). 날씨→프롬프트→이미지→발송 파이프라인을 구축하고 이미지 품질 문제를 프롬프트 엔지니어링으로 개선.

> *5인 팀의 팀장을 맡았습니다. 제출용 스냅샷 레포라 개인별 코드 기여를 나눠 표시할 수 없어, 아래는 팀 산출물 기준으로 적었습니다.*
